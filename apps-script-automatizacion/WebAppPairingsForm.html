Generar Pairings

Las opciones de Filial / Flota / Sub flota salen de lo que REALMENTE existe en la base de datos para el mes elegido (no son listas fijas). 1. "Ver vista previa" consulta BigQuery con los filtros actuales. Desde ahí, las 3 se cruzan en vivo (como Looker): marcas una casilla y las demás se recalculan al toque (unos segundos, contra BigQuery), mostrando solo las combinaciones que de verdad existen en la data — la vista previa muestra como máximo 300 filas, pero el contador de arriba siempre es el total real. El tipo de carga siempre es FP (no es un filtro — así se definió el flujo). 2. "Generar candidatos" aplica las reglas de LCK — acá SOLO importa qué Sub flota marcaste (Flota queda fuera de este paso: es un filtro independiente que solo sirve para explorar la data cruda en el paso 1, no para decidir qué reglas correr). 3. "Generar Google Sheet" arma el archivo final.
